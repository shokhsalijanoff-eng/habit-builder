# Product Vision Statement

## Product Name
Habit Builder

## Vision

Habit Builder is a simple web application designed to help users
create, manage, and track their daily habits in one place.

## Problem

People often want to build positive habits but may forget their
daily goals or have difficulty tracking their progress consistently.

## Target Users

The target users are students and individuals who want a simple
way to organize and track their daily habits.

## Core Value

Habit Builder provides a simple interface where users can:

- Add new habits
- View their habits
- Mark habits as completed
- Delete habits
- Keep habit data between sessions

## Current MVP

The current MVP was first developed as a Python command-line
application and later converted into a Flask web application.
The web application is deployed online using Render.

## Future Direction

Future versions may include:

- Habit streaks
- Daily progress statistics
- Better user interface
- Database storage
- User accounts
- Cloud-based persistent data
